## multiband
### OVERVIEW
`multiband` is a pitch shifting tool for Windows. for using it in Linux/Unix, use Wine.
it is an alternative by YellowGreenGMD to `multipitch`.
### DOWNLOADS
*in multiband.exe!*
### USAGE
basic pitching: multiband.exe --engine ffmpeg input.wav output.wav -- 12,-5
preserved formants: multiband.exe --engine ffmpeg input.wav output.wav --preserve-formants -- 12,-5
